# Rilis APK KaderCare

Repositori publik khusus berkas unduhan aplikasi HP KaderCare (SIP-Posyandu).
Kode sumber tetap privat di `viikidna/sip-posyandu`.

Kader mengunduh lewat halaman `/unduh` di web desa — tombolnya selalu menunjuk
rilis terbaru di sini (`kadercare-arm64.apk` / `kadercare-v7a.apk`).
